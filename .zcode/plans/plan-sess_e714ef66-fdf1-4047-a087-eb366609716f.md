# Exam Prep — Chatbot Exam Wizard ("collect all files, then take the exam")

## The flow on your phone
1. **Library → Exams card → "New exam"** → opens a **chat with the wizard**
2. You tell it naturally: *"Midterm next week — it covers programming and SDLC"* (or paste the teacher's announcement)
3. The wizard checks your library against the announced topics and replies, e.g.:
   - ✓ "I found your **Programming Basics** PDF — that covers the programming part."
   - ⚠ "Nothing in your library covers **SDLC** yet — please upload those notes before we continue."
4. You **upload missing files directly in the chat** (attach button → same local extraction pipeline as Import) — after each upload the wizard re-checks coverage
5. A live **coverage checklist** shows every announced topic → covered by which file / still missing
6. Once everything is covered, a **"Create exam"** button appears → the exam is saved with all matched files + topics → then **Start practice quiz** (questions mixed across ALL the files) and **Export PDF handout**

Online requirement: the chatbot needs the AI relay (internet). If offline, the chat explains that and offers the manual create form instead — core app stays offline-first.

## Implementation

### 1. Data layer — `storage.js` + `db-types.ts`
- IndexedDB **v9** migration, new `exams` store: `{ id, accountId, title, examDate?, createdAt, announcement, docIds[], topics: [{title, docId, reason}], status }` + CRUD (`saveExam/getExam/listExams/deleteExam`)

### 2. AI chat brain — new `src/lib/llm/exam-ai.js`
- `examChat(messages, libraryDigest, examDraft)`: sends conversation + library digest (each doc's name/topics/key terms) to the existing relay, requesting JSON: `{ reply, examTitle?, examDate?, topics: [{title, reason}], matchedDocIds: [], missingTopics: [], readyToCreate }`
- The free-text `reply` drives the conversation; the structured fields drive the app's coverage checklist and exam draft — best of both
- Prompt in `prompts.js` (strict JSON, grounded in the digest, never invents files you haven't uploaded)
- Offline: throws cleanly → chat shows "AI chat needs internet" + link to the manual create form

### 3. Chat screen — new `src/ui/screens/exam-chat.js`
- Wizard chat bubbles + typing indicator + message input
- **Attach button in chat**: file picker → existing local extraction pipeline (`extractText`) → `saveDoc` → wizard re-checks coverage automatically
- **Coverage checklist panel**: announced topic → ✓ covered by file / ⚠ missing
- **Create exam** button (enabled only when the wizard marks it ready) → `saveExam` → exam detail

### 4. Exam screens — new `src/ui/screens/exams.js`
- List of exams (upcoming with countdown, past), detail view: matched files, ranked topics with reasons, **Start practice quiz** + **Export PDF handout** + delete

### 5. Multi-file exam quiz — new `src/lib/exam.js`
- `buildExamQuiz(exam, docs, weakTerms)`: `generateQuiz` per doc (questions spread across all files, biased toward weak spots), tags each question `meta.docId`, seeded-shuffles the merge — deterministic and unit-testable. Quiz session rides a new `state.examSession` mode in `quiz.js`/`main.js` (mirrors mistakeReview; cross-doc mistake banking already works)

### 6. Library card + PDF — `library.js`, `export.js`
- Upcoming exam card at the top of Your library → opens the exam
- `exportExamPdf`: title/date, ranked topics with reasons, per-doc notes via existing jsPDF setup

### 7. Tests — `tests/exam-prep.test.js`
- `buildExamQuiz` multi-doc attribution + determinism, exam CRUD round-trip, exam-chat JSON parsing (canned AI responses), offline keyword matching fallback
